# smart-rehabilitation-glove
Developing an ESP32-based wearable system for finger motion tracking using flex sensors.

# components
Microcontroller: ESP32 / Arduino Uno
Sensors: Flex Sensors (for finger bending detection)
Motion Sensor (Optional): MPU6050 / Accelerometer
Communication Module: Wi-Fi (ESP32 built-in)
Power Supply: 5V Battery / USB Power
Connecting Wires: Jumper wires
Resistors: For voltage divider with flex sensors
Glove Material: Fabric glove for mounting sensors
