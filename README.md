# IoT-Based Smart Rehabilitation Glove

An ESP32-based wearable system designed for finger-motion tracking and rehabilitation monitoring using flex sensors.

## 📌 Project Overview

The system tracks finger movements using flex sensors and an ESP32 microcontroller. The collected sensor data can be used to monitor rehabilitation exercises and visualize exercise progress.

## 🎯 Objectives

* Track finger movements using flex sensors
* Process sensor data using ESP32
* Monitor rehabilitation exercises
* Provide real-time data visualization
* Support remote monitoring through IoT
* Enable offline operation without an active internet connection or Wi-Fi
